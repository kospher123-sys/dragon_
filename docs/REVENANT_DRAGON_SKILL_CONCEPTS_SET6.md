상태: 시각 참고 자료 / 게임 미구현 / 사용자 선호 미수집

5열×2행 이미지 시트 순서(왼쪽에서 오른쪽으로):
1. 장송의 하프 / Requiem Harp — 골격 하프가 영혼 음파를 발사
2. 영혼의 모래시계 / Soul Hourglass — 거대한 모래시계 속에서 영혼이 흘러내림
3. 사령 단두대 / Spectral Guillotine — 골격 단두대 칼날 낙하
4. 백골 전차 돌격 / Ossuary Chariot Charge — 유령 짐승이 끄는 뼈 전차 돌진
5. 탄식의 대성당 / Cathedral of Laments — 유령 창이 빛나는 골격 성당에서 빛줄기 발사
6. 망자의 관렬 / Coffin Procession — 공중의 관들이 열려 영혼을 방출
7. 죽음의 골필우 / Necrotic Quill Rain — 룬이 새겨진 거대한 뼈 깃펜 낙하
8. 무명의 망자 가면 / Mask of the Nameless Dead — 거대한 장례 가면의 영혼 파동
9. 묘지까마귀 폭풍 / Grave Raven Tempest — 골격 까마귀 떼가 돌진
10. 사령 유물함 / Reliquary of the Dead — 보물함 형태 유물 장치에서 무기와 사령 에너지 분출

선호 또는 채택 여부는 아직 지정되지 않았으며 모든 항목은 후보이다. 첨부 이미지 원본은 GitHub에 아직 포함되지 않는다. 기존 스킬 구성과 코드 변경 없음.
