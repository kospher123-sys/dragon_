# 망령 드래곤 추가 스킬 — 3차 8종 시각 콘셉트

- 날짜: 2026-11-16
- 상태: **후속 제작 참고 기획 / 게임 미구현 / 원본 이미지 GitHub 미등록**
- 이미지: 사용자가 대화에 첨부한 4×2 시트(3차). 패널 1–4는 윗줄 왼쪽부터, 5–8은 아랫줄 왼쪽부터.
- 선호: **1·3·4·7번**. 나머지 2·5·6·8은 **미선정**이며 폐기 결정은 아님.

| # | 스킬 | 이미지 표현 | 평가 |
|---|---|---|---|
| 1 | 왕의 골창 (King's Bone Lance) | 하늘에서 왕실 의식 장식이 달린 거대한 뼈 창이 낙하해 지면 충격파 발생 | **향후 제작 참고** |
| 2 | 갈비뼈 감옥 (Ribcage Prison) | 거대한 갈비뼈가 지면에서 솟아 적을 둘러쌈 | 미선정 |
| 3 | 유령의 등불 (Ghost Lanterns) | 공중에 여러 개의 청록색 영혼 등불이 떠다니며 적에게 접근 | **향후 제작 참고** |
| 4 | 혼령 낙뢰 (Soulfall Lightning) | 하늘에서 영혼 형상을 품은 청록 낙뢰가 적 진영에 여러 차례 낙하 | **향후 제작 참고** |
| 5 | 영혼의 강 (River of Souls) | 지면을 따라 수많은 유령이 흐르는 강물이 적 진영을 휩씀 | 미선정 |
| 6 | 침묵의 종언 (Funeral Bell) | 거대한 유령 종이 울리며 원형 파동이 퍼짐 | 미선정 |
| 7 | 사령익 참격 (Spectral Wing Cleave) | 드래곤 날개에서 넓은 초승달 형태의 영혼 참격이 적에게 날아감 | **향후 제작 참고** |
| 8 | 영체 이탈 (Astral Dragon Charge) | 영혼체 드래곤이 본체에서 분리되어 전방 돌진 | 미선정 |

## 사용자 피드백
> 1,3,4,7 번 괜찮아 보이네 이번것도 푸시해줘 다음 8개 프롬프트 만들어줘

## 실제 개발 시 주의
- 기존 `SPEC.md`의 종족별 **4슬롯(공격/방어/생활/궁극기)** 과 자동 전투 방향을 임의로 바꾸지 않는다.
- 이 시트는 **1컷 시각적 레퍼런스**이지 투명 배경 애니메이션이나 배포 에셋이 아니다.
- 스킬 효과, 발동/유지/종료 프레임, 타격 판정, 밸런스는 추후 별도 결정한다.
- 1·2차 후보 및 기존 스킬과 중복 검토 후 작업 순서를 확정한다.
- 원본 이미지 파일은 이 문서에 포함되어 있지 않다. 추후 실제 업로드 시 파일 링크를 추가한다.
