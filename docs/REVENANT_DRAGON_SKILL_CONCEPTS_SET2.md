# 망령 드래곤 추가 스킬 — 2차 8종 시각 콘셉트

- 날짜: 2026-11-16
- 상태: **후속 제작 참고 기획 / 게임 미구현 / 원본 이미지 GitHub 미등록**
- 이미지: 사용자가 대화에 첨부한 4×2 시트(2차). 패널 1–4는 윗줄 왼쪽부터, 5–8은 아랫줄 왼쪽부터.
- 선호: **2·3·7·8번**. 나머지 1·4·5·6은 **미선정**이며 폐기 결정은 아님.

| # | 스킬 | 이미지 표현 | 평가 |
|---|---|---|---|
| 1 | 망자의 거수 (Giant Hand of the Dead) | 거대한 뼈 손이 땅에서 솟아 적을 움켜쥠 | 미선정 |
| 2 | 백골림 (Bone Forest) | 적 진영에 여러 뼈 창이 산림처럼 연달아 솟음 | **향후 제작 참고** |
| 3 | 사골윤무 (Bone Blade Orbit) | 드래곤 주위에 곡선 뼈 칼날이 회전하며 적을 향해 날아감 | **향후 제작 참고** |
| 4 | 원혼의 포효 (Wailing Skull Roar) | 거대한 유령 해골이 포효하며 영혼 충격파 방출 | 미선정 |
| 5 | 혼백 개화 (Soul Bloom Detonation) | 청록색 영혼 꽃이 피면서 폭발함 | 미선정 |
| 6 | 망령 군단 (Phantom Legion) | 반투명 영혼 병사 무리가 진군함 | 미선정 |
| 7 | 영혼의 족쇄 (Soul Shackles) | 공중 룬진과 지면을 잇는 영혼 사슬이 적을 묶음 | **향후 제작 참고** |
| 8 | 저승의 균열 (Nether Rift) | 적 진영에 거대한 청록·검은 차원 균열이 열림 | **향후 제작 참고** |

- 기존 `SPEC.md`의 종족별 **4슬롯(공격/방어/생활/궁극기)** 과 자동 전투 방향을 임의로 바꾸지 않는다.
- 이 시트는 **1컷 시각적 레퍼런스**이지 투명 배경 애니메이션이나 배포 에셋이 아니다.
- 스킬 효과, 발동/유지/종료 프레임, 타격 판정, 밸런스는 추후 별도 결정한다.
- 1차 8종 콘셉트와 중복 검토 후 작업 순서를 확정한다.
- 원본 이미지 파일은 이 문서에 포함되어 있지 않다. 추후 실제 업로드 시 파일 링크를 추가한다.
