# 그림자 드래곤 스킬 기획 v0.1

작성일: 2026-11-14  
상태: 신규 제안 / 밸런스 검증 전 / 게임 미구현  
요청 범위: 패시브·할퀴기·브레스·마법 방어막·궁극기 5종.

## 1. 캐릭터 방향

**그림자를 새기고, 마법을 버틴 뒤, 쌓인 어둠을 터뜨리는 드래곤.**

첨부 이미지의 검은 비늘·보라색 날개막·낮고 길게 뻗은 실루엣을 따른다. 빠르게 난타하는 암살자보다 차분하게 대상을 압박하는 마법형 전투원이다.
할퀴기는 표식을 준비하는 물리 공격, 브레스는 표식을 활용하는 마법 공격, 방어막은 마법을 흡수해 다음 공격을 강화하는 수단이다.
궁극기는 비행 모션을 활용한 넓은 그림자 폭발이다. 소환수·부활·영혼 수집은 이번 콘셉트에 넣지 않는다.

강점: 마법 적 상대, 표식을 쌓은 대상 집중 공격, 다수 적 마무리.  
약점: 물리 집중 공격, 표식 준비 전 짧은 전투, 방어막이 의미 없는 물리 적 조합.

## 2. 공통 규칙과 수치 기준

- 아래 수치는 플레이 테스트용 제안이다. A는 시전자 공격력, H는 시전자 최대 HP다.
- 기존 전투처럼 '턴'은 해당 드래곤의 행동 1회다. 지속 2턴 효과는 시전 직후부터 다음 두 행동이 끝날 때까지 유지하고, 두 번째 행동의 효과 계산 후 만료한다.
- 할퀴기·브레스·궁극기는 각각 행동 1회를 사용한다. 방어막은 자동 조건 발동으로 행동을 소모하지 않는다.
- 재사용 대기는 해당 스킬을 쓴 이후의 자기 행동으로 센다. 3턴 대기라면 다음 세 행동 동안 사용 불가, 네 번째 행동부터 가능하다.
- 모든 공격 계수는 방어·기존 피해 보정 전 기본값이다. 적중한 타격만 표식을 부여하며 빗나감·취소는 부여하지 않는다.
- 일반 피해 감소와 방어 계산 → 보호막 흡수 → HP 감소 순으로 처리한다. 마법 판정은 이펙트 색이나 적 이름 대신 공격 데이터의 피해 유형을 사용한다.
- 표식과 흡수 강화는 시전자별로 관리한다. 전투 종료·시전자 사망 시 해당 시전자의 임시 상태를 제거한다.
- 화면 밝기·실제 밤낮·앱 실행 시간에 따른 전투 보너스는 없다.

## 3. 다섯 가지 스킬

| 구분 | 이름 | 핵심 효과 | 제안 제한 |
|---|---|---|---|
| 패시브 | 어둠의 각인 | 할퀴기·브레스 적중 시 대상에게 그림자 표식 1개. 3개에서 자동 폭발 | 대상별 최대 3개, 지속 3턴 |
| 할퀴기 | 그림자 발톱 | 적 1명에게 100% A 물리 피해, 표식 1개 | 기본 공격, 재사용 대기 없음 |
| 브레스 | 황혼의 숨결 | 적 전체에 총 150% A 마법 피해를 균등 분배, 각 적에게 표식 1개 | 재사용 대기 3턴 |
| 마법 방어막 | 흑막의 비늘 | 마법 피해만 흡수하는 12% H 보호막. 흡수하면 다음 브레스 또는 궁극기 강화 | 지속 2턴, 전투당 1회 |
| 궁극기 | 영야의 날개 | 적 전체에 총 220% A 마법 피해를 균등 분배하고 각 대상의 표식 소모 | 자기 행동 4회 이후, 전투당 1회 |

### 패시브 — 어둠의 각인

할퀴기 또는 브레스가 적중하면 대상 발밑에 그림자 표식 1개를 새긴다.
표식이 3개가 되면 그 대상에게 **45% A 추가 마법 피해**를 주고 전부 소모한다. 폭발은 다른 적에게 전파되지 않는다.

- 표식이 추가되면 남은 지속 시간을 3턴으로 갱신한다. 부여한 행동은 지속 시간에서 차감하지 않는다.
- 폭발 피해는 표식을 다시 만들지 않는다. 다단 연출을 해도 스킬 1회당 대상별 부여는 1회다.
- 세 번째 표식을 부여한 공격의 기본 피해를 먼저 처리하고, 대상이 생존하면 폭발을 처리한다.
- 대상 사망·표식 정화 시 폭발 없이 제거한다. 표식은 일반 해로운 효과로 정화 가능하다.
- 보스도 표식과 폭발 피해를 받는다. 행동 불가 효과가 없어 보스 면역 예외는 필요 없다.
- 연출: 발밑에 보라색 초승달 1~3개, 세 번째에서 안쪽으로 수축 후 짧은 먹빛 파열.

### 할퀴기 — 그림자 발톱

앞발을 낮게 당겼다가 대각선으로 긋는다. 적 1명에게 **100% A 물리 피해**를 주고 표식 1개를 부여한다.

- 집중 공격 명령의 대상을 우선한다. 없으면 현재 표식이 가장 많은 적, 동률이면 HP 비율이 낮은 적, 다시 동률이면 전투 내 고정 순서를 따른다.
- 공격 중 순간이동·무적은 없다. 잔상은 시각 효과다.
- 몸 모션은 첨부 `dragon_attack_12_v2.png`를 우선 검토한다.
- 12프레임 제안: 1~4 준비 / 5~7 긋기 / 8~12 회수. 타격 이벤트는 6번 프레임에 1회만 둔다.
- 프레임 배분은 제안이며 실제 발끝 위치 확인 후 조정한다.
- 연출: 세 줄의 보라색 발톱 궤적과 짧은 검은 잔상. 본체가 안 보일 정도로 덮지 않는다.

### 브레스 — 황혼의 숨결

검보라색 안개를 전방으로 내뿜는다. 전투에서는 적 전체에게 **총 150% A 마법 피해를 균등 분배**하고, 각 생존 대상에게 표식 1개를 부여한다.

- 피해는 적중 시점의 생존 적 수로 나눈다. 적 1명이면 150%, 3명이면 각 50% A다. 각 대상에 방어·적중 판정을 별도로 적용하며 빗나간 몫은 재분배하지 않는다.
- 궁극기와 달리 표식을 직접 소비하지 않는다. 3개에 도달한 대상만 패시브 폭발이 발생한다.
- 방어막 흡수 강화가 있으면 기본 브레스 피해만 ×1.2, 총 180% A가 된다. 패시브 폭발은 강화하지 않는다.
- 연출: 입의 보라색 빛 → 낮게 퍼지는 안개 → 발밑 그림자. 지속 피해처럼 보여도 판정은 1회다.
- 첨부에는 전용 브레스 모션·브레스 이펙트가 확인되지 않았다. 입 벌리기·목 젖히기·내뿜기·회수와 별도 안개 이펙트를 추가 제작한다.

### 마법 방어막 — 흑막의 비늘

첫 마법 공격이 들어오기 직전 자동으로 발동한다. **최대 HP 12% 용량의 마법 전용 보호막**을 2턴 동안 생성한다.

- 전투당 1회. 시전자가 살아 있고 행동 불가 상태가 아닐 때만 발동한다. 마법 공격이 없으면 사용하지 않는다.
- 첫 공격도 즉시 흡수한다. 물리·고정 피해는 흡수하지 않으며 방어막 용량을 깎지 않는다.
- 마법 지속 피해도 마법 유형이면 흡수한다. 디버프·제어 효과 자체를 무효화하지 않는다.
- 실제 피해를 1 이상 흡수하면 '흡수한 어둠' 강화 1회를 얻는다. 여러 번 맞아도 중첩하지 않는다.
- 강화는 다음 브레스 또는 궁극기의 기본 피해만 20% 증가시키고 소모된다. 할퀴기·표식 폭발·궁극기 표식 추가 피해에는 적용하지 않는다.
- 강화는 획득 이후 자기 행동 3회까지 유지하며 세 번째 행동 계산 뒤 만료한다. 이미 있을 때 흡수해도 기한을 연장하지 않는다.
- 보호막 파괴·자연 만료는 별도 반격 피해를 발생시키지 않는다. 강화는 보호막과 별개로 남는다.
- 연출: 몸을 감싸는 반투명 보라색 비늘막. 흡수할 때 안쪽으로 흐르고, 강화 보유 중 가슴에 작은 빛을 남긴다.

### 궁극기 — 영야의 날개

날개를 펼쳐 짧게 떠오른 뒤, 바닥에 거대한 날개 그림자를 드리우고 접어 폭발시킨다.

- 자기 행동 4회를 마친 뒤 다음 행동부터 사용 가능하다. 전투당 1회이며, 생존 적 중 표식 2개 이상인 적이 있으면 자동 사용한다.
- 7회를 마친 뒤에는 표식 조건 없이 다음 행동에서 사용해 지나친 보류를 막는다.
- 적 전체에 **총 220% A 마법 피해를 균등 분배**한다. 기본 피해 적중 후 살아 있는 각 대상의 표식을 모두 소비하고, 1개당 **25% A 추가 마법 피해**를 준다.
- 표식 추가 피해는 대상별 계산이며 분배하지 않는다. 소비 직전 0~2개가 일반적인 상태다. 3개는 패시브가 즉시 폭발하므로 보통 남아 있지 않는다.
- 궁극기는 표식을 새로 부여하지 않고 패시브 폭발도 발생시키지 않는다. 빗나간 대상의 표식은 소비하지 않는다.
- 흡수 강화 시 기본 피해만 총 264% A로 증가한다. 무적·공포·시간 정지·처형 효과는 없다.
- 연출 중 떠오르는 동작은 시각 효과이며 타겟팅·피해 면역을 바꾸지 않는다.
- 비행 본체는 `dragon_flight_12_reference_v3.png`를 참고한다. 거대 날개 그림자·수축·폭발은 추가 제작한다.
- 화면 전체를 검게 덮지 않는다. 바탕화면에서는 대상 주변 바닥에만 그림자를 표시한다.

## 4. 자동 전투 운용

행동 선택 우선순위: 궁극기 조건 충족 → 브레스 사용 가능 → 할퀴기.
마법 방어막은 피격 직전 별도 조건 판정이며 행동 순서에 끼어들지 않는다.

예시: 1행동 할퀴기(표식 1) → 2행동 브레스(표식 2) → 3행동 할퀴기(3개 폭발·초기화) → 4행동 할퀴기(1개) → 5행동 할퀴기(2개) → 6행동 궁극기(표식 소비).
실제 순서는 대상 생존·집중 공격 명령·브레스 재사용 대기에 따라 달라진다. 마법 방어막을 통해 얻은 강화는 브레스나 궁극기의 피해를 높이지만, 스킬 사용 조건을 건너뛰지는 않는다.

공격 모션과 이펙트는 분리하고 피해 판정은 애니메이션 프레임 수와 독립된 이벤트로 관리한다.

## 6. 기존 프로젝트와 연결할 때의 결정

현재 `src/engine/data.ts`는 12종, `src/engine/skills.ts`는 공격·방어·생활·궁극기의 4슬롯이다.
이번 요청은 패시브 + 기본 할퀴기 + 브레스 + 방어막 + 궁극기 체계이므로, 기존 4슬롯에 단순히 다섯 항목을 추가하면 맞지 않는다.

후속 구현 제안:
- 그림자 드래곤은 기존 흑염룡·흑요석과 구분하는 신규 종족으로 설계한다. 실제 종족 번호·획득처·레어 위치는 별도 확정한다.
- 패시브와 기본 할퀴기는 슬롯 바깥의 전투 규칙으로 둔다.
- 공격 슬롯=황혼의 숨결 / 방어 슬롯=흑막의 비늘 / 궁극기 슬롯=영야의 날개.
- 생활 슬롯은 이번 범위에 없으며 미정이다. 기존 생활 스킬을 임의로 복사하지 않는다.
- 마법 방어막은 현재 공통 피해 처리와 별도로 피해 유형·보호막 용량·피격 직전 발동 지점을 구현해야 한다.
- 전투 상태에 시전자별 대상 표식, 브레스 대기, 보호막 용량·기한, 흡수 강화, 궁극기 사용 여부를 둔다.
- 기존 세이브의 종족 인덱스를 바꾸지 않고 신규 값을 끝에 추가한다. 그림·색상·종족 수 고정 반복·레어 배열도 함께 점검한다.
- 바탕화면 조종은 연출 프리뷰와 전투 규칙을 구분한다. 클릭 반복으로 표식·방어막 효과를 실제 전투에 중복 적용하지 않는다.

**이번 업데이트는 기획 문서 반영이다. 게임 코드·종족 목록·세이브·배포 파일과 원본 이미지 업로드는 변경하지 않는다.**

## 7. 후속 검증 기준

- 같은 A·H의 기존 종족과 단일 적 / 3명 적 / 물리 적 / 마법 적 / 혼합 적을 비교한다. 승률뿐 아니라 행동당 피해와 방어막 실제 흡수량을 본다.
- 할퀴기 3회 시 표식 폭발은 정확히 1회이며 자기 재발동이 없어야 한다.
- 브레스 다단 연출에도 표식은 대상당 1개만 생기고, 단일 적과 다수 적의 총 기본 피해는 동일해야 한다.
- 궁극기는 표식 소모와 패시브 폭발을 중복 계산하지 않아야 한다.
- 방어막은 첫 마법 피해부터 흡수하고, 물리·고정 피해에는 작동하지 않아야 한다.
- 재사용 대기·지속 기한·행동 불가·빗나감·대상 사망·정화·전투 종료를 각각 확인한다.
- 방어막과 궁극기를 초기에 전투당 1회로 제한해 장기전 반복 증폭을 막는다. 표식 계수와 광역 총 피해는 검증 후 조정한다.
