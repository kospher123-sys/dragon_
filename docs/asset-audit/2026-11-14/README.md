## 저장소와 기존 규칙 확인

- 시작점: main `38b556f` (기존 그림자 원본 및 수정 후보 포함). 기존 SPEC.md, DEVLOG.md, docs/SHADOW_DRAGON_SKILL_DESIGN.md, 그림자드래곤/README.md 및 review_v2/REVIEW.md를 읽었다.
- SPEC §9의 실행용 규칙은 `public/img/sk-motion-NN.png` (3열×4슬롯, 290×240 셀), `sk-NN-MM.png` (최대 400×300), 평면 경로다. 새 PNG들은 이 규격과 같지 않으며 신규 종족 번호도 확정하지 않았다.
- 따라서 실행용 이름·기존 슬롯을 임의 배정하지 않고, 기존 `assets-src` 원본 보관 경로 아래 `dragon-skills/2026-11-14/revenant/<원래 패키지명>/`에 원래 이름과 폴더를 보존했다. 그림자 파일은 기존 `그림자드래곤/` 경로 그대로다.
- 작업 순서: 기존 기획 확인 → 실재 파일·ZIP 대조 → 모션/이펙트/프레임 분류 → 원본 보관 및 검증 기록. 후속 단계는 품질 보정·기준점과 방향 정합 → 재생·합성 검수 → 종족/슬롯 및 효과 연결 설계 → 실행용 변환·구현·테스트다. 기존 개발 순서를 바꾸거나 구현 완료로 표시하지 않는다.

## 조사 범위와 출처

- 참조 대화 `6af537fc-adb8-83ec-8d86-b9e7928b9e5a`를 읽었다. 검색 응답의 첨부 목록은 비어 있었고, 메시지의 `DRAGON_TOWER_SKILL_ICON_PACK_V1.zip`은 명시적으로 아이콘 14종 패키지였다. 모션·이펙트로 취급하지 않았다. 해당 sandbox 링크의 파일 바이트는 이번 세션에서 제공되지 않았다.
- 프로젝트 루트, output의 오늘 작업 산출물·ZIP, 두 로컬 저장소, Downloads의 ZIP 목록을 조사했다. 로컬 파일 수정 시각은 오늘 작업과 일치하지만 생성 시각의 독립 증명은 아니므로 매니페스트에 제한을 기록했다.
- 망령룡 ZIP 11개는 CRC 검사와 PNG 전량 SHA-256 대조를 통과했다. 압축본 자체는 중복 저장하지 않았다. README.txt와 원본 manifest.json은 패키지별로 함께 보관했다.
- 그림자 제작 키트 및 스킬별 첨부 ZIP 6개는 참고 이미지·프롬프트 패키지다. CRC를 검사하고 내부 경로를 기록했으며, 새 스킬 결과물로 반입하지 않았다.
- 그림자 원본 16장은 프로젝트 루트, 수정 후보 16장은 output/shadow_review_v2의 동명 파일과 SHA-256이 일치했다. 이미 main에 존재하므로 재업로드·덮어쓰기를 하지 않았다.

## 검증 결과와 한계

- PNG 330개 전부 디코딩, 크기·채널·알파 실측, 복사 전후 및 기존 파일 해시 대조. 망령룡 원본 manifest의 모든 프레임 경로가 실재하고, 개별 프레임은 444×444다.
- 전체 시트·아틀라스를 축소 비교 화면으로 시각 확인했다. 망령룡의 뼈대/청록색 영혼 모션과 독립 이펙트, 그림자의 본체/보라색 표식·안개·방어막·폭발이 식별되며 스킬 아이콘은 포함되지 않았다. 이 시각 확인은 픽셀 단위 미술 검수나 애니메이션 재생 검증이 아니다.
- 망령룡은 원본 README가 지적한 색 테두리·매트 흔적, 일부 이펙트 경계 잘림, 몸체/기준점 차이가 남는다. 투명 알파가 있다는 사실만으로 합성 품질 통과를 선언하지 않는다. 제안 시간·방출 프레임은 게임에서 검증되지 않았다.
- 그림자 시트는 실제 1448×1086 / 셀 362×362이며 요청 2048×1536 / 512×512에 미달한다. 기존 review_v2/REVIEW.md의 형태·중심·방출점·루프 문제와 바닥 그림자 후보 채택 보류를 유지한다.
- 실제 게임 합성·재생·피해 판정·종족 연결은 미검증이다. 이미지 파일 검증과 최종 사용 승인을 구분한다. 새 이미지를 생성하거나 확대·수정하지 않았다.

## 누락·미반영

1. 망령룡 ‘죽음의 행렬’의 별도 군대·전장·소환 이펙트: 오늘 산출물에서 찾지 못했다. 원본 manifest도 `army_and_battlefield_effects_included: false`다. 본체 모션을 이펙트로 중복 계수하지 않았다.
2. 그림자 스킬의 개별 프레임 PNG, 최종 규격 시트 및 최종 승인본: 찾지 못했다. 기존 시트를 임의 분할·승격하지 않았다.
3. 참조 대화의 스킬 아이콘 통합 ZIP 바이트: 현재 첨부 목록과 조사한 로컬 경로에서 확인되지 않았다. 메시지상 아이콘 패키지이므로 이번 범위에서 제외한다.
4. 기존 기획의 `shadow_dragon_sprites_collection.zip` 원본 전체: 현재 output에서 동명 ZIP을 확인하지 못했다. 제작 키트의 ref_* 이미지·참고용 걷기/휴식/비행은 새 스킬 결과물로 포함하지 않았다.
5. 제작 프롬프트, 생성 도구 경로가 든 source.json, 비교용 썸네일, UI 가이드, 무관한 코드 및 중복 ZIP은 반입하지 않았다. 필요한 출처와 스킬 식별은 매니페스트 및 원본 README에 기록했다.

기존 추적 파일, 게임 코드, public/img 및 배포 파일 변경 없음. 모든 신규 내용은 별도 브랜치의 추가 파일이며 main 병합은 PR 검토 대상으로 남긴다.
