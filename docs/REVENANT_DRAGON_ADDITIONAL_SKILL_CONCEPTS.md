# 망령 드래곤 추가 스킬 콘셉트 — 1차 8종

작성일: 2026-11-16  
상태: **시각 기획 / 게임 미구현 / 스킬 확정 전**  
관련 문서: [개발 기준](../SPEC.md)

## 목적과 기존 개발 순서와의 관계
- 기존 종족 4슬롯(공격·방어·생활·궁극기) 및 자동 전투 구조를 변경하지 않는다.
- 이번 8종은 **추가 스킬 아이디어와 실제 게임 화면 연출 참고용**이며, 구현 순서를 앞당기거나 기존 4슬롯에 자동 배정하지 않는다.
- 사용자가 승인한 것은 1·2·3·5·6·7번의 **향후 제작 참고 가치**이지, 최종 스킬 채택·밸런스·구현 승인까지는 아니다.
- 별도 이미지 시트는 사용자 대화에 첨부된 4열×2행 원본 이미지이며, 현재 이 문서에 파일 자체를 포함하지 않았다. 향후 저장소 이미지 등록 시 이 문서에서 상대 경로로 연결할 것.

## 원본 이미지의 패널 순서
왼쪽에서 오른쪽으로 첫째 줄 1~4, 둘째 줄 5~8이다.

| 2 | Ossuary Heaven | 백골천궁 | 상공에 거대한 뼈 성채가 구성되고 뼈 창이 적에게 낙하 | **향후 제작 참고** |
| 3 | Soul Core Overload | 영혼핵 과부하 | 갈비뼈 속 영혼핵에서 전방으로 집중 광선, 주변에 원형 마력 고리 | **향후 제작 참고** |

## 사용자 평가 — 원문 의미 보존
> “너무 이쁘게 잘나왔어 1,2,3,5,6,7번은 다은에 제작할떄 참고해야할것 같아 굳굳”

- 첫 번째 이미지 시트 전반의 시각적 완성도를 긍정적으로 평가함.
- 1·2·3·5·6·7번을 **후속 제작 레퍼런스**로 표시함.
- 4·8번에 대한 부정적 평가나 폐기 요청은 없었으므로 **미선정/보류**로만 취급한다.

## 공통 시각 기준
- 망령 드래곤: 풍화된 상아·회백색 골격, 긴 경추, 가지 친 뿔, 갈비뼈 내부 청록 영혼핵.
- 비대칭 손상의 골격 날개, 반투명 청록 영혼막, 네 다리, 뼈 꼬리, 낡은 사슬.
- **고정 측면 게임 카메라**, 드래곤 왼쪽·적 오른쪽, 어두운 폐허 전장.
- 이펙트의 중심 색은 청록·옅은 청록·영혼빛 흰색; 한눈에 스킬 차이가 보여야 한다.
- 홍보 포스터가 아니라 **게임에서 발동 중인 1컷**의 참고 이미지.
- 원본 한 장은 4열×2행 시트. 각각은 아직 투명 배경의 애니메이션 에셋이 아니다.

## 후속 적용 전에 필요한 절차
1. 원본 8패널 이미지 시트를 별도 레퍼런스 파일로 보관하고 출처/패널 번호를 유지한다.
2. 기존 종족별 4슬롯 스킬, 효과 엔진, 전투 UI와 비교하여 새 스킬의 목적 및 기존 기술 중복 여부를 확인한다.
3. 우선 참고 6종 중 구현 후보를 고르되, 시각 콘셉트 승인과 게임 규칙 승인을 구분한다.
4. 발동·유지·종료, 타격 시점, 투사체·소환물 위치, 반복/종료 조건을 각각 기획한다.
5. 실제 이펙트 제작 시 투명 배경·프레임 분리·기준점·해상도 검수 후 게임에 적용하고 성능/가독성을 테스트한다.

## 범위 제외
이번 기록은 **신규 기획 메모**만 다룬다. 코드 변경, 기존 스킬 슬롯 교체, 전투 수치 확정, 배포 빌드 수정, 애니메이션 제작 완료로 해석해서는 안 된다.
