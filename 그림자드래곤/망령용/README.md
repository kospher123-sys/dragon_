# 망령용 스킬 이미지 V1

업데이트: 2026-11-14

이 폴더는 오늘 생성한 망령용 스킬 본체 모션과 분리형 효과의 V1 검토 자료입니다. 캐릭터 본체와 효과 프레임은 별도 폴더로 정리했습니다.

| 폴더 | 내용 |
|---|---|
| 01_basic_attack_body / 02_basic_attack_effects | 기본 공격 원거리·근접 본체 모션 및 투사체·충격·발톱 효과 |
| 03_spirit_pierce_body / 04_spirit_pierce_effects | Spirit Pierce 시전 모션 및 차지·관통·적중 효과 |
| 05_soul_harvest_body / 06_soul_harvest_effects | Soul Harvest 흡수 모션 및 영혼 구체·이동·흡수 효과 |
| 07_spectral_erosion_body / 08_spectral_erosion_effects | Spectral Erosion 시전 모션 및 확산 안개·유령 손·피해 펄스 |
| 09_underworld_breath_body / 10_underworld_breath_effects | Breath of the Underworld 시전 모션 및 영혼 브레스 효과 |
| 11_march_of_the_dead_body / 12_march_of_the_dead_effects | March of the Dead 궁극기 시전 모션 및 의식·영혼 군대 효과 |

각 세트에는 분리 프레임, 아틀라스 또는 소스 시트, 재생 정보와 생성 프롬프트가 포함된 경우 이를 함께 보관했습니다. 세트별 README와 manifest를 참조하세요.

**검수 상태:** 생성된 V1 초안입니다. 최종 게임 적용 승인은 아닙니다. 일부 프레임에는 가장자리 색 번짐, 형태 차이, 중심점·정렬 오차가 남아 있을 수 있습니다. 실제 게임 크기에서의 합성 및 애니메이션 재생 검증은 완료되지 않았습니다.
