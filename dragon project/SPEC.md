# 흑염룡 연대기 데스크톱 — 개발 기준 (SPEC)

사람용 기획서: Claude Docs 「흑염룡 연대기 데스크톱 기획서」. 이 문서는 코드 기준으로 그 내용을 정리한 것이다.

## 1. 구조

```
src/engine/   게임 규칙 (순수 TypeScript, 화면·파일 접근 없음)
  data.ts     시간 상수(TIME_SCALE), 종족·지역·레어·마을 데이터
  engine.ts   상태, 시간 진행(step), 명령(act), 전투, 따라잡기(catchUp), 웹 저장 가져오기(importWeb)
src/main/     Electron 메인 프로세스: 진행 루프, 저장, 트레이, 알림, 창, IPC
src/shared/   설정·IPC 타입
src/renderer/ 관리 창 (React) + 전투 팝업(#battle)
public/img/   그림 파일 (빌드 시 dist/renderer/img 로 복사)
test/         엔진 자동 테스트 (vitest)
tools/        밸런스 시뮬레이션(balance.ts), 확인용 저장 파일 생성(seed.ts)
```

게임 엔진은 메인 프로세스에서만 돈다. 창은 0.5초마다 상태(snapshot)를 받아 그리고, 동작은 `act` 명령으로 보낸다.

## 2. 시간

- `TIME_SCALE = 3`: 웹 버전보다 3배 느림. 기간 상수는 곱하고 초당 회복량은 나눈다. 전투 속도는 배율 없음.
- 진행 루프: 200ms마다 실제 경과 시간을 0.5초 단위로 나눠 `step`. 한 번에 1초까지만 진행.
- 30초 넘게 끊기면(절전·정지) 꺼져 있던 것으로 보고 `catchUp`.
- 시작 시: 저장 시각부터 지금까지를 `catchUp` (최대 `CATCHUP_MAX` = 8시간). 일시정지 상태로 저장했으면 따라잡지 않는다.
- 따라잡기 시간이 `SUMMARY_MIN`(10분) 이상이면 요약 창.

## 3. 웹 버전과 다른 규칙

| 항목 | 웹 버전 | 이 버전 |
|---|---|---|
| 시간 | 1일 20분 | 1일 1시간 (모든 기간 ×3) |
| 지원 요청 | 세계 정지 후 선택 | 정지 없음, 5분 안에 선택, 없으면 자동 거절(친밀도 −8). 따라잡기 중에는 생성 안 함 |
| 새 흑염룡 이름 | 세계 정지 후 입력 | 자동 이름, 관리 창에서 변경. 첫 흑염룡만 시작 화면에서 입력 |
| 따라잡기 | 없음(탭 숨기면 정지) | 최대 8시간 |
| 꺼져 있던 동안 보호 | 없음 | 따라잡기 중 체력이 바닥나면 사망 대신 후퇴(HP 1), 함락돼도 알 손실 없음 |
| 레어 함락 시 사망 | 기록 없음 | 쓰러진 드래곤을 사건으로 기록 |
| 귀환 임무 | 출발지 정보 없음 | `mission.from` 으로 지도 경로 표시 |

### 밸런스 근거 (tools/balance.ts, 새 연대기, 아무 조작 없음, 200회)

| 꺼져 있던 시간 | 보호 전 혈통 종료 | 보호 전 첫 흑염룡 사망 | 보호 후 |
|---|---|---|---|
| 4시간 | 13% | 61% | 0% / 0% |
| 8시간 | 26% | 87.5% | 0% / 0% |

보호 후 8시간 따라잡기의 평균: 습격 8.7회, 함락 6.5회, 살아 있는 흑염룡 15.9마리. 죽는 일이 없어 개체 수가 빠르게 늘어나므로, 장기적으로 개체 수 상한이 필요할 수 있다(미결).

## 4. 저장

- 위치: `%APPDATA%\흑염룡\` (`BLACKFLAME_DATA` 환경 변수로 바꿀 수 있음, 테스트용)
  - `world.json` 현재 저장, `world.backup.json` 직전 저장, `settings.json` 설정, `archives\` 지난 연대기
- 형식: `{ format: 'blackflame-desktop-save', savedAt(epoch ms), paused, state }`
- 저장 시점: 30초마다(변경 있을 때), 사망·함락·습격·부화·지원 요청 직후, 명령 직후, 일시정지, 종료, 절전 진입.
- 쓰기: 임시 파일에 쓴 뒤 교체(rename), 기존 파일은 backup으로 복사.
- 불러오기: 새 형식 또는 웹 버전 JSON(`blackflame-local` 서버 저장 파일, 또는 웹에서 내보낸 state). 웹 버전 시간 값은 ×3. 현재 연대기는 archives에 보관 후 교체.
- 읽기 실패 시: backup 시도 → 실패하면 손상 파일을 `world.json.broken-<시각>`으로 남기고 새로 시작.

## 5. 알림

엔진 이벤트 kind → 설정 키: raid/fall→레어 습격, hatch→부화, return→사냥 귀환, death→사망, visit→방문 이벤트(다른 종의 알 맡김), support→지원 요청, over→혈통 종료. 습격 알림 클릭 → 전투 창, 지원 요청 클릭 → 관리 창.

## 6. 바탕화면 (2차)

- 구조: 선택한 모니터의 작업 영역(workArea) 크기의 투명·항상 위·포커스 없는 창 **하나**(`src/main/desktop.ts`)에 캔버스로 모든 요소를 그린다(`src/renderer/desktop/overlay.ts`). 드래곤마다 창을 만들지 않아 마릿수가 늘어도 창 수는 그대로다.
- 클릭 통과: 기본은 `setIgnoreMouseEvents(true, {forward:true})`. 마우스가 둥지·버튼·드래곤·(조종 모드일 때) 몬스터 위에 올라가면 그때만 클릭을 받는다.
- 표시 대상: `settings.desktop[id] ?? (home === 0)` 인 살아 있는 드래곤. 1초마다 모델을 받아 생기면 등장(다른 레어 드래곤은 화면 밖에서 날아옴), 빠지면 사라짐.
- 드래곤 행동: 걷기 55% / 비행 20% / 둥지로 가서 잠 15% / 대기 10%. 클릭하면 대사. 엔진 알림 중 해당 드래곤 소식은 말풍선으로도 표시.
- 둥지: [조종하기] [관리 창] 버튼, 끌어서 이동(위치 저장), 알 최대 3개(부화 1분 전부터 금 간 알).
- 조종 모드: 몬스터 클릭 → 표시 중 드래곤 1마리 + 스킬 4종 중 1개 무작위. 1초에 1회, 이펙트 동시 1개(진행 중 클릭은 버림). 60초 무공격 시 자동 해제. 드래곤 0마리면 버튼 비활성.
- 몬스터: 슬라임·고블린·오우거·리치 4마리 상시. 작업 영역 바닥(작업표시줄 바로 위, 작업표시줄이 아래가 아니거나 자동 숨김이면 화면 맨 아래)을 걷는다. 맞으면 0.3초 피격 → 5초 기절(기울기·반투명·별) → 0.5초 회복. 기절 중 다시 맞으면 5초 재시작.
- 성능: 고사양 60fps·이펙트 원본·파티클 / 저사양 30fps·이펙트 50%·파티클 없음. 저사양에서 7마리 이상 표시 시 레어 탭에 안내.
- 전체화면 자동 숨김: 2초마다 전경 창이 표시 모니터를 완전히 덮는지 검사(koffi로 user32 호출, `src/main/fullscreen.ts`). 숨김 중 알림은 모았다가 끝나면 최대 3개 + "외 N건". 실패하면 기능만 꺼지고 게임은 계속.
- 그림 교체: `%APPDATA%\흑염룡\img\` 에 같은 이름 PNG를 넣으면 `bf://img/` 프로토콜이 그 파일을 우선 사용(다음 실행부터, 칸 배치 동일해야 함).
- 아이콘: 패키징 후 `tools/seticon.mjs`(resedit)로 exe 아이콘·제품명 교체.

### 미결 / 알려진 한계
- 다른 종 7종은 4종 그림의 색조 변경. 다른 종 걷기는 그림 1장 + 출렁임 연출.
- 몬스터 그림에 걷기·피격·기절 전용 프레임이 없어 대기/공격 4프레임을 걷기로 쓰고 기절은 코드 연출.
- 보호 규칙으로 장기 방치 시 개체 수가 계속 늘 수 있음(상한 미정).

### 실험 규칙 (State.rules, act 'rule', 테스트판 기본 켬)
- defense 레어 총력 방어: 습격 시 건강한 성체(HP>30%) 최대 3 합류 → 수호자 공격 ×(1+0.35n), 피해 1/(1+0.5n) 수호자·나머지 합류자(HP 20% 하한), 수호자 HP<25%면 dt×0.5 확률 후퇴, 함락 피해 ×0.5
- depletion 사냥터 고갈: State.yields[지역], 승리 시 보상 (30+5×위험도)×풍요도, 풍요도 −0.25(최소 0.15), 회복 1/3600 per s, 알아서 사냥 가중치 위험도×풍요도²
- parallel 동시 사냥: 다른 전투 중 도착한 사냥은 s.battle을 잠시 비우고 battleStep을 0.5초씩 최대 2400번 돌려 결과만 낸 뒤 원래 전투 복원
- tactics 전술 전투: Battle.morale(100), 쓰러진 적 1명당 −20(집중 공격 중 −30), 치명타 −8, ×(몬스터 0.5·결투 0.7·인간 1), 0이면 승리. act 'command'(focus/guard/roar/retreat), Battle.order·orderReady, 대기 8초, 지속 6초
- 바탕화면 방어전(테스트판 항상): DesktopModel.raid{defended,max}, desk:defend → act 'defend' (Battle.defended ≤ 15, 적 유닛 −3.5% max, 사기 −5). 오버레이: 습격 동안 자동 조종·제한 없음, 3.5~5.5초마다 원정대(최대 6), 침입자 격퇴 시 호출
- 숙적 State.nemesis: 결투 승리 시 50%로 생성, 도전의 50%가 숙적(레벨당 전력 +40%), 3패하면 유물 +150 후 사라짐

## 9. 종족 고유 스킬 (v1.4.0, 실험 규칙 `skills`)
- 데이터: `src/engine/skills.ts` — `SPECIES_SKILLS[종족][슬롯]` (슬롯 0 공격 · 1 방어 · 2 생활 · 3 궁극기). 이름·작동 방식·바탕화면 요소·설명·`area`(전투에서 적 전체를 나눠 치는지)·`fx`(이펙트 배치)·`implemented`(고유 효과 구현 여부, 지금은 모두 false).
- 그림: `python3 tools/build_skill_assets.py <01_정리본_12종> <보완_추가_이미지>` 로 다시 만든다.
  - `sk-motion-NN.png` 3열(준비·발동·회수) × 4행(슬롯), 칸 290×240, 칸 바닥 = 발바닥. 원본은 3컷 키포즈(각 724×724)에서 발바닥 기준 위로 600px.
  - `sk-NN-MM.png` 정리본 NN 종족 MM번 이펙트, 투명 여백 제거·최대 400×300. 오른쪽(대상 쪽)을 향한 그림 기준이며 드래곤이 왼쪽을 보면 뒤집는다.
  - `bf://img/` 프로토콜은 하위 폴더를 무시하므로 모두 `public/img` 바로 아래에 둔다(`%APPDATA%\흑염룡\img\` 덮어쓰기도 같은 이름으로 된다).
- 엔진: 규칙이 켜져 있으면 `SKILLS(d, s)` = [공격, 방어, 궁극기, 파멸의 발톱]. 피해 공식은 기존과 같고 범위(전체/단일)만 `area`를 따른다 → 밸런스 변화 없음.
- 바탕화면(`overlay.ts`): `DesktopModel.skills`. 조종 모드·방어전 공격은 슬롯 가중치 공격 0.45 · 방어 0.25 · 궁극기 0.3, 대상 옆 땅에 내려앉아 `SKILL_TIME` 1.35초 시전(타격 판정 0.5 시점). 생활 스킬은 낮·비조종·비방어전에 45~110초마다 한 마리 `LIFE_TIME` 2.8초. 이펙트 위치 종류는 `FxAt` 주석 참고. 꽃시계는 실제 시각으로 꽃이 바뀐다.
- 전투 창(`Battle.tsx`): `b.skill`이 종족 스킬이면 1.5초 동안 3컷 모션 + 이펙트(드래곤 쪽/적 무리 쪽 단순 배치).
- 관리 창: 드래곤 상세 '고유 스킬' 카드 4장(발동 컷, 분류, 설명, 구현 상태).
- 남은 일: 스킬별 고유 효과(효과 시스템: 버프·디버프·보호막·행동 불가·스택), '아군 필요' 12개 처리 방향, 생활 스킬의 커서·실제 시간 판정, 스킬 아이콘, 3컷 사이 보간 프레임.

## 10. '아군 필요' 12개 혼자 판본 (v1.5.0, 실험 규칙 `skills` 안)
- 결정(2026-11-08): 아군 = 레어 총력 방어 합류 드래곤. 혼자 싸울 때는 자기에게 걸리는 대체 효과. 아군 판본은 아직 없음 → 합류 드래곤이 있어도 혼자 판본.
- 코드: `src/engine/skillfx.ts` — `SOLO_SKILLS`(12개), `SOLO_DESC`(설명, `SkillDef.solo`로 관리 창에 표시), 상태 `Battle.solo`.
  - `soloTurnStart`: 드래곤 행동 시작마다 턴 +1, 지속 효과(회복·기생·구전·동굴) 처리, 쉬는 행동(동굴·맞불 대가) 판정.
  - `soloResolve`: 조건 미달·횟수 소진·이미 걸린 스킬 → '파멸의 발톱'.
  - `soloAttack`: skills 규칙일 때 기존 피해 적용 코드를 대신한다(범위 ×1.4 분배·단일·집중 공격 규칙은 같음).
  - `soloIncoming` / `soloAfterHit`: 적 공격 보정(동굴·빗나감·맞불·가마·허들·금박) / 밀랍 인장 판정.
  - `SOLO.on`: 밸런스 비교용 스위치.
- '턴' = 시전한 드래곤의 행동 1회(2~4초). 'N턴' = 시전 뒤 행동 N번. '큰 공격' = 용사 공격 또는 약점 강타(적 예고 기능이 생기면 예고 공격으로 바꿀 것).
- 수치는 기획 원안보다 크게 낮췄다(혼자 판본은 대상이 1명이라 같은 수치면 너무 강함). 원안 대비 주요 차이: 금박 40%·3턴 → 8%·1턴, 구전 ×0.7 → ×0.08, 접순 기생 → 기본 피해 8%, 능선 누적 +0.4 → +0.1.
- 밸런스: `npx tsx tools/balance-skills.ts 600` — 종족별 같은 전투(공격력 60·생명력 900, 적 전력 700/1000)를 효과 켬/끔으로 비교. 전력 1000(승률 약 80% 구간)에서 승률 차이 −2.3~+5.3%p. 이 구간은 생명력 몇 %로 후퇴 여부가 갈려 민감하다(금박 보호막 63 → +12%p였음).
  - `SKILLS=1 SOLO=0|1 npx tsx tools/balance-growth.ts 30 8`: 실험 규칙 켠 8시간 성장 비교.
